Available Scripts 🚀

In the project directory, you can run:

##npm start

Starts the app in development mode.

Open 👉 http://localhost:3000
 in your browser.

The page reloads automatically when you make changes.

##npm test

Runs the test runner in watch mode.

Useful for checking if your code is working as expected.

##npm run build

Creates a production-ready build in the build folder.

Optimized for speed and performance (minified + hashed files).

Use this build for deployment.

##npm run eject ⚠️

Advanced option – not for beginners.

Copies all hidden configuration (Webpack, Babel, ESLint, etc.) so you can customize everything.

Once you eject, you cannot go back.

Only use if you really need deep customization.
